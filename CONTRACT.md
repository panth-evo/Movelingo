1. PRODUCT
Relocation planner plus language-learning engine. The language plan is driven by the move deadline and by the CEFR level the visa or job route requires.
Languages: de, es, fr, it.   Levels: A1 A2 B1 B2 C1.
Exam skills: reading, listening, writing, speaking.   Extra bars (practice only): vocabulary, grammar.

4. PROGRESS BAR RULES (deterministic, no LLM, time in the app never fills a bar)
B stores per (user, language, level, skill): attempted, correct (rolling window of the last 60 answered items), exam_best (best ratio of the last 3 graded sections).
Writing and speaking tasks count as 6 attempted per graded task, correct = 6 x task ratio (constant PRODUCTIVE_WEIGHT = 6).
  practice_mastery = min(1, attempted/60) * (correct/attempted)      (0 when attempted = 0)
  skill_progress   = round(100 * (0.6*practice_mastery + 0.4*exam_best))
  A skill is certified when a graded exam section for that level+skill reached ratio >= spec.pass_ratio (default 0.6).
  skill_progress is capped at 99 while not certified (safety cap); certified forces 100. With the default pass_ratio an uncertified skill tops out at 84 anyway.
  level_progress = mean of the four exam-skill progress values (vocabulary and grammar bars are shown, not averaged).
  level.status: certified (all 4 exam skills certified) | in_progress (first non-certified level, or any level with progress > 0) | locked.
  current_level = first level that is not certified. A placement result marks every level below the placed level certified (source=placement).
  target_level = plan.required_level.

8. EXAM REALISM RULES (UI and generator both obey)
- One countdown per section from spec duration_min. No pause. Auto-submit at zero.
- Listening: show preview_seconds to read the items, then play each segment at most its play_limit times; no rewind or scrubbing; fixed part order.
- Reading parts can be done in any order unless spec.order_fixed is true.
- Writing: live word counter against min_words/max_words. Speaking: prep_seconds countdown, then recording; the AI plays the examiner or partner.
- Exam mode hides hints and dictionaries. Practice mode may show them.
- Specs marked derived:true are labelled "practice format, not official timing" in the UI.

9. QUALITY GUARDS
- The LLM never decides a CEFR level or pass/fail. Code does, using spec thresholds.
- Reading and listening are marked from answer keys only.
- Writing and speaking: the LLM returns criterion bands taken from spec.criteria only; code turns bands into points; result has ai_estimated=true and the UI says "AI estimate".
- Generated parts must pass validators: item count and types equal spec, exactly one correct key per item, text length within spec range. Retry up to 2 times, then fall back to a cached sample in data/exam_specs/<spec_id>/samples/.
- Never paste official exam papers into prompts or the repo. Use structure only. All texts and audio scripts are newly written.
- Visa and cost data come only from official government sites, stored with source_url and last_verified. Unknown stays null. UI shows "Not legal advice, check the official site".
